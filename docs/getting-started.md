# Get started with Community Script Samples

A useful script can save hours. Start with a scenario someone has already solved, understand how it works, and adapt it to your environment.

## 1. Find the task you want to automate

[Open the gallery](index.md) and search for a task or command, such as a site inventory, sharing links, or `Get-PnPSite`. Use the product buttons and tool, scenario, and contributor filters together to narrow the results.

Samples cover SharePoint, Microsoft Graph, Teams, Microsoft Copilot, Power Platform, Azure, and more. Open a sample to see its purpose, authors, prerequisites, and script implementations.

## 2. Choose your tool

Many samples show the same task using different tools. Select the matching tab and read the complete instructions before copying any code.

Use the sample's tested versions as context, not a guarantee of compatibility with every release. Check the linked tool documentation for current installation and authentication instructions.

## 3. Review, adapt, and test

- Read the whole README and script, including permissions, dependencies, and any warnings.
- Replace example URLs, IDs, file paths, and other placeholders with appropriate values. Never paste credentials into shared code.
- Use only the permissions the task needs. Review how authentication works for your chosen tool.
- Test against non-production data first. Review any operation that changes or removes data, and plan for recovery where appropriate.

> [!WARNING]
> Some samples modify permissions, deploy resources, or delete data. Do not run code you have not reviewed. Community samples are provided as-is, without warranty.

## 4. Make it better for the next person

If a sample helped, share its gallery link and credit the authors. If something is unclear or no longer works, [report an issue](https://github.com/pnp/script-samples/issues/new) with the sample name, tool version, and a redacted description of the problem.

You can also [improve a sample or share your own](contributing/index.md). You do not need to know how the website is built.
